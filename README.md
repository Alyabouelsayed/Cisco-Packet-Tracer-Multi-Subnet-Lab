# 🌐 Multi-Subnet Network Infrastructure with DHCP & DNS (Cisco Packet Tracer)

## 📌 Project Overview
This project demonstrates a complete multi-segment enterprise network architecture built and tested in **Cisco Packet Tracer**. It covers core networking fundamentals, including inter-VLAN routing, centralized IP address management via DHCP, and name resolution through a dedicated DNS server[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).

## 🛠️ Network Architecture & Implementation
* **Topology:** A multi-subnet network topology connected centrally via a Cisco router, segmenting traffic across different departments/VLANs[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).
* **DHCP Server Configuration:** Configured a dedicated server to automatically distribute dynamic IPv4 addresses across network segments using router helper (`ip helper-address`) configurations[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span).
* **DNS Server Integration:** Deployed and configured a local DNS server to handle domain name lookups[span_8](start_span)[span_8](end_span)[span_9](start_span)[span_9](end_span).
* **Testing & Validation:** Successfully validated end-to-end connectivity, automated IP configuration, and service availability using `ping` and DHCP request verification[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span)[span_12](start_span)[span_12](end_span)[span_13](start_span)[span_13](end_span).
